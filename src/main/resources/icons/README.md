# Application icon

`fedora.png` is the 1024px transparent master used by the window and Dock.
`fedora.icns` and `fedora.ico` contain multiple sizes for native packages.
The artwork was generated with the built-in imagegen tool, then resized with
ImageMagick and packaged with macOS `iconutil`. Transparent padding keeps the brim
clear of icon boundaries.

## Generation prompt

```text
Use case: stylized-concept
Asset type: desktop application icon, square 1024x1024 canvas
Primary request: Indiana Jones's iconic brown fedora hat alone, instantly recognizable silhouette: tall pinched crown, deep center crease, broad slightly curled brim and dark brown grosgrain ribbon. No person.
Style/medium: polished illustrated 3D app icon, softly sculpted felt with restrained warm highlights, strong simple silhouette readable at 32px.
Composition/framing: a single centered hat viewed slightly from above in three-quarter view, brim spans about 86% of canvas width, balanced compact composition with safe transparent padding on all sides.
Color palette: warm sable brown felt, very dark chocolate ribbon, amber highlights.
Scene/backdrop: genuinely transparent background, isolated object with alpha, no tile or background plate.
Constraints: only the fedora; no text, letters, logos, watermark, whip, face, head, other props, or floating specks.
```
